OpenAPI

The OpenAPI specifications provide a formal standard for describing HTTP APIs. If an API provides an OpenAPI Description (OAD), that description can be used to discover all the endpoints and their available operations.

The OpenAPI specification was originally based on the Swagger Specification developed by SmartBear Software. Therefore, you will see the term "Swagger" still being used in many places.
Add an OpenAPI description

  1. Add the Microsoft.AspNetCore.OpenApi NuGet package to the AddressBook.API project.

  2. Add the OpenAPI services.

    builder.Services.AddOpenApi();

  3. Add the OpenAPI middleware before the call to UseAuthentication

    if (app.Environment.IsDevelopment()) {
  app.MapOpenApi();
}

    It is common to only enable OpenAPI when running in a development environment but there are scenarios when you may choose to enable it in production (e.g., to support external client-side developers).

  4. Run the app and make a request with a Web browser to http://localhost:5000/openapi/v1.json

Configuration

The document name (default of v1) can be customized by passing a name to AddOpenApi

builder.Services.AddOpenApi("addressbook");

The endpoint address can also be customized by passing a route to MapOpenApi. The value for the documentName parameter is based on how the service is configured.

app.MapOpenApi("/openapi/{documentName}/openapi.json");

A collection of attributes exist that can be applied to endpoints to augment the information that appears in the OpenAPI document.

[HttpPut("customer/{id}")]
[EndpointSummary("Replaces an existing customer or creates a new one")]
[ProducesResponseType(StatusCodes.Status201Created)]
[ProducesResponseType(StatusCodes.Status204NoContent)]
public ActionResult PutCustomer(string id, Customer customer) {

Refer to the documentation for more information about customization options and other available tools.

Swagger UI

The Swashbuckle.AspNetCore.SwaggerUi NuGet package can be used to render a UI for the generated document. This provides an easy way to visualize and interact with an API.

Add a dynamic UI

  1. Add the Swashbuckle.AspNetCore.SwaggerUi NuGet package to the AddressBook.API project.

  2. Add the middleware immediately after the call to MapOpenApi and include the route to the OpenAPI document.

    if (app.Environment.IsDevelopment()) {
  app.MapOpenApi();
  app.UseSwaggerUI(options => {
    options.SwaggerEndpoint("/openapi/v1.json", "v1");
  });
}

  3. Run the app, navigate to http://localhost:5000/swagger, and explore the UI.
