.NET Platform

Microsoft’s first release of a product named .NET was in February 2002. Although it had the potential to be cross-platform, it was only officially supported on the Windows operating system. The Windows-only version of .NET is still supported but is now specifically referred to as .NET Framework.

In November 2014, Microsoft introduced an open-source, cross-platform successor to .NET Framework named .NET Core. The first several versions of .NET Core focused on Web-based workloads and did not include all the features offered by .NET Framework.

In November 2020, Microsoft released a new version of .NET Core but rebranded it as simply .NET 5. The "Core" branding was dropped and this variant became the primary version of .NET recommended by Microsoft for all future development.

Every November since 2020, Microsoft has released a new major version of .NET:

Support Policy

Even numbered major releases of .NET are LTS (Long Term Support) releases that get free support and patches for three years. Odd numbered releases are STS (Standard Term Support) releases that get free support and patches for two years.

The main .NET download page has information about each .NET version including end of support dates.

It is critical to avoid having any apps in production that use a version of the .NET Runtime that is no longer supported. Versions that have reached their end of support date will not receive bug fixes or security patches.

Open Source

The entire .NET platform is now developed in the open on GitHub with all the source code visible to the public. It is possible to contribute code by submitting a pull request but all contributions go through a rigorous review process before becoming part of the product.
