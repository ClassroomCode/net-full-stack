Development Environments

Although it’s possible to develop .NET apps using only a text editor and the free SDK, most developers prefer to use a more full-featured development environment. In this section, we will mention the three most popular development environments for .NET - Visual Studio, Visual Studio Code, and Rider.

Visual Studio

Visual Studio is Microsoft’s most comprehensive IDE for .NET developers using Windows. Visual Studio is available in three different editions - Community (free), Professional, and Enterprise. For a list of the differences, refer to this page on the Microsoft website.

After acquiring Xamarin in 2016, Microsoft announced "Visual Studio for Mac" which was a rebranded version of Xamarin Studio. However, Microsoft has since retired Visual Studio for Mac (August 2024) and now recommends Visual Studio Code with the C# Dev Kit extension for .NET developers using macOS.

Visual Studio Code

Visual Studio Code is a cross-platform code editor developed by Microsoft for Windows, Linux, macOS, and web browsers. In a recent Stack Overflow Developer Survey, Visual Studio code ranked as the most popular developer environment tool (73% of respondents).

The downloadable version of Visual Studio Code is built using the open-source Electron framework. Electron uses Node.js and a version of the Chromium browser engine to allow for the development of cross-platform desktop apps with JavaScript, HTML, and CSS.

Out of the box, Visual Studio Code includes support for HTML, CSS, JavaScript, and TypeScript. Through the use of extensions, support can be added for almost every other modern programming language including C, C++, C#, Java, Go, PHP, Python, and Rust. Recent versions also include integration with GitHub Copilot.

Basic C# language support is provided by the official Microsoft C# extension. This extension provides features such as IntelliSense code-completion, formatting, refactoring, and navigation commands such as "Go To Definition" and "Find All References".

Microsoft’s C# Dev Kit extension builds on top of the C# extension by adding more features to help with file management, unit testing, and debugging. The C# Dev Kit extension is recommended for all .NET development and Visual Studio code will automatically prompt you to install this extension when you open a C# file.

Installing the C# Dev Kit will also trigger the base C# extension to be installed (if it is not already).

There are many other extensions for Visual Studio Code that you my find useful including ones for Azure, AWS, Docker, and GitHub Copilot.

Rider

Rider is a cross-platform .NET IDE from JetBrains that provides a development experience that is very similar to Visual Studio, and it has been steadily gaining in popularity. Many .NET developers prefer Rider because of its advanced profiling/decompilation tools and its integration with the popular ReSharper tool.

In October 2024, JetBrains announced a change to their licencing model allowing Rider to be used for free for non-commercial purposes. This includes learning, open-source projects, content creation, and hobby development.
