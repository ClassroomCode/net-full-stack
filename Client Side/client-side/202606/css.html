CSS

Introduction

CSS is a style sheet language used for describing the presentation of a document written in HTML. CSS describes how elements should be rendered on screen, paper, or in other media.

Default Styles

Each web browser includes a set of default styles that it applies to HTML elements. These styles can vary between browsers, which is why you may notice differences in how your web pages look across different browsers.

There are many CSS reset stylesheets available that can help standardize the appearance of HTML elements across different browsers. These stylesheets remove the default browser styles, allowing you to start with a clean slate.

CSS Syntax

CSS is made up of selectors and declarations. A selector points to the HTML element you want to style, and a declaration consists of a property and a value.

h1 {
  color: red;
  font-size: 2.5em;
}

Browser Rendering

When a web browser loads a web page, it first converts the HTML document into a DOM (Document Object Model) tree. Any CSS rules are then applied to the DOM to create a render tree which is then painted to the browser window.

Adding CSS to an HTML Document

There are three different ways to apply CSS to an HTML document — external stylesheets, internal stylesheets, and inline styles.

External Stylesheets

An external stylesheet is a separate CSS file that you link to from your HTML document. This is the most common method of applying styles, as it allows you to keep your CSS separate from your HTML, making it easier to maintain.

To add an external stylesheet, use the <link> element in the <head> section of your HTML document:

<link rel="stylesheet" href="styles.css">

Internal Stylesheets

An internal stylesheet is defined within the <style> element in the <head> section of your HTML document. This method is useful for applying styles to a single page without needing a separate CSS file.

<head>
  <style>
    body {
      background-color: lightblue;
    }
    h1 {
      color: navy;
      font-size: 2.5em;
    }
  </style>
</head>

Inline Styles

Inline styles are applied directly to an HTML element using the style attribute. This method is generally not recommended for large projects, as it can make your HTML cluttered and harder to maintain.

<h1 style="color: red; font-size: 2.5em;">Hello, World!</h1>

If CSP (Content Security Policy) is enabled, inline styles may be blocked. In such cases, it is better to use external or internal stylesheets to ensure your styles are applied correctly.

Selectors

CSS selectors are patterns used to select the elements you want to style. They can be simple or complex, depending on the elements you want to target.

Type Selectors

Type selectors are the most basic type of selector. They select elements based on their type (or tag name). For example, to select all <p> elements, you would use the p selector.

p {
  color: blue;
  font-size: 16px;
}

You can also select multiple types of elements by separating them with commas. For example, to select all <h1> and <h2> elements, you would use:

h1, h2 {
  color: green;
  font-weight: bold;
}

ID Selector

The ID selector selects a single element with a specific ID attribute. To select an element with the ID unique, you would use:

#unique {
  background-color: yellow;
  padding: 10px;
}

You can apply the ID to one element only:

<div id="unique">This is a unique element with the ID "unique".</div>

Class Selector

The class selector selects elements with a specific class attribute. To select all elements with the class example, you would use:

.example {
  font-size: 1.2em;
  color: purple;
}

You can apply the same class to multiple elements:

<p class="example">This is a paragraph with the example class.</p>
<h1 class="example">This is a heading with the example class.</h1>

You can also require multiple classes by separating them with a dot. For example, to select elements with both class1 and class2, you would use:

.class1.class2 {
  border: 1px solid black;
  padding: 5px;
}
<p class="class1 class2">This paragraph has both class1 and class2.</p>

Universal Selector

The universal selector selects all elements in the document. It is represented by an asterisk (*). For example, to apply a margin to all elements, you would use:

* {
  margin: 0;
}

If chained with a descendant combinator, it can apply styles to all elements within a specific parent. For example, to select all elements inside a <div>, you would use:

div * {
  color: gray;
}

Attribute Selector

The attribute selector selects elements based on the presence or value of an attribute. For example, to select all <a> elements with a href attribute, you would use:

a[href] {
  text-decoration: none;
  color: orange;
}

You can also select elements with a specific attribute value:

a[href="https://example.com"] {
  color: red;
}

Attribute Selectors

An attribute selector allows you to select elements based on the presence or value of an attribute. This is particularly useful for styling elements that have specific attributes, such as links or form inputs.

Basic Attribute Selector

The basic attribute selector selects elements that have a specific attribute, regardless of its value. For example, to select all <input> elements with a type attribute, you would use:

input[type] {
  border: 1px solid #ccc;
  padding: 5px;
}

Attribute Value Selector

You can also select elements based on the value of an attribute. For example, to select all <input> elements with a type attribute equal to text, you would use:

input[type="text"] {
  background-color: #f0f0f0;
  color: #333;
}

Substring Matching Selectors

You can select elements based on a substring of an attribute value. There are several types of substring selectors:

  • ^=: Selects elements whose attribute value starts with a specified value.

  • $=: Selects elements whose attribute value ends with a specified value.

  • *=: Selects elements whose attribute value contains a specified substring.

For example, to select all <a> elements whose href attribute starts with https, you would use:

a[href^="https"] {
  color: green;
  text-decoration: underline;
}

Pseudo-Classes

A pseudo-class is a keyword added to selectors that specifies a special state of the selected elements. Pseudo-classes are used to style elements based on their state, position, or other characteristics that cannot be targeted with simple selectors.

<article>
  <p>
    Some text.
  </p>
  <p>
    Some other text.
  </p>
</article>
article p:first-child {
  font-size: 120%;
  font-weight: bold;
}

There are a large number of pseudo-classes available in CSS. For a complete list, you can consult the MDN documentation or the HTML specification.

User-Action Pseudo-Classes

Some pseudo-classes are based on user actions, such as hovering over an element or focusing on an input field. These pseudo-classes allow you to change the style of an element when a user interacts with it.

<input type="text" placeholder="Focus on me">
<button>Hover over me</button>
input:focus {
  border: 2px solid blue;
  outline: none;
}
button:hover {
  background-color: lightblue;
  color: darkblue;
}

Pseudo-Elements

Pseudo-elements are similar to pseudo-classes but are used to style specific parts of an element rather than the entire element. They allow you to apply styles to elements that do not have a specific class or ID.

<p>
  This is a paragraph.
</p>
p::first-letter {
  font-size: 2em;
  color: red;
}

Inserting Content

You can use the ::before and ::after pseudo-elements to insert content before or after an element’s content. This is useful for adding decorative elements or additional information without modifying the HTML structure.

<p>
  This is a paragraph.
</p>
p::before {
  content: "Note: ";
  font-weight: bold;
  color: green;
}
p::after {
  content: " (End of paragraph)";
  font-style: italic;
  color: gray;
}

Combinators

Combinators in CSS are used to define relationships between selectors. They allow you to select elements based on their relationship to other elements in the document tree. There are four main types of combinators: descendant, child, adjacent sibling, and general sibling.

Descendant Combinator

The descendant combinator is represented by a space between two selectors. It selects all elements that are descendants of a specified element, regardless of their depth in the hierarchy. For example, to select all <p> elements inside a <div>, you would use:

div p {
  color: blue;
}

Child Combinator

The child combinator is represented by a greater-than sign (>). It selects only the direct children of a specified element. For example, to select all <li> elements that are direct children of a <ul>, you would use:

ul > li {
  list-style-type: square;
  color: green;
}

Next-Sibling Combinator

The next-sibling combinator is represented by a plus sign (+). It selects an element that is immediately preceded by a specified element. For example, to select the first <p> element that follows an <h2>, you would use:

h2 + p {
  margin-top: 10px;
  color: purple;
}

Combining Combinators with Selectors

You can combine combinators with other selectors to create more specific rules. For example, to select all <span> elements that are direct children of a <div> and have a class of highlight, you would use:

div > span.highlight {
  background-color: yellow;
  font-weight: bold;
}

Box Model

Every element in HTML has a box model that defines its dimensions and spacing. Understanding the box model is crucial for effective layout and design in CSS.

Block Elements

Block elements are the building blocks of the box model. They create a rectangular box that occupies the full width available, with a new line before and after the element. Some common block elements include <div>, <p>, <h*>, <ul>, <ol>, and <li>.

Semantic HTML elements like <header>, <footer>, <section>, <article>, and <nav> act the same as <div> in terms of the box model, but they provide better structure and meaning to the document.

For block elements, width and height properties are respected.

Inline Elements

Inline elements do not create a new line and only take up as much width as necessary. They flow within the text and do not respect the width and height properties. Common inline elements include <span>, <a>, <strong>, <em>, and <img>.

Parts of a Box

The box model consists of several layers:

  • Content: The actual content of the box, such as text or images.

  • Padding: The space between the content and the border.

  • Border: The line surrounding the padding and content. It can have different styles, widths, and colors.

  • Margin: The space outside the border that separates the box from other elements.

Standard Box Model

By default (the standard box model), the width and height properties control the size of the content box. To calculate the total size of an element, you need to consider padding, border, and margin.

.box {
  width: 200px; /* Content width */
  padding: 10px; /* Padding on all sides */
  border: 5px solid black; /* Border on all sides */
  margin: 20px; /* Margin on all sides */
}
/* Total width = content width + padding + border + margin */

Alternative Box Model

The alternative box model, defined by the box-sizing property, changes how the width and height of an element are calculated. When set to border-box, the width and height include padding and border and the size of the content box is adjusted accordingly.

.box {
  box-sizing: border-box;
  width: 200px; /* Total width including padding and border */
  padding: 10px; /* Padding on all sides */
  border: 5px solid black; /* Border on all sides */
  margin: 20px; /* Margin on all sides */
}
/* Total width = 200px (includes padding and border) + margin */

Some developers choose to use the alternative box model globally because it simplifies layout calculations, especially when dealing with padding and borders.

html {
  box-sizing: border-box;
}

*,
*::before,
*::after {
  box-sizing: inherit;
}

More information about this specific technique can be found here.

Margins

The margin is the outermost layer of the box model. It creates space between the element and its surrounding elements.

You can set margins for all sides using the margin property, or specify individual margins using margin-top, margin-right, margin-bottom, and margin-left.

.box {
  margin: 20px; /* Margin on all sides */
}
.box {
  margin-top: 10px;
  margin-right: 15px;
  margin-bottom: 10px;
  margin-left: 15px;
}

Margin collapsing occurs in vertical margins of block elements. For example, if two paragraphs have a margin of 20px, the space between them will be 20px, not 40px. More information about margin collapsing can be found here.

Padding

Padding is the space between the content and the border of the box. It can be set for all sides using the padding property or individually using padding-top, padding-right, padding-bottom, and padding-left.

Borders

Borders are the lines that surround the padding and content of the box. You can set the border’s width, style, and color using the border property or specify individual borders using border-top, border-right, border-bottom, and border-left.

.box {
  border: 2px solid black; /* Border on all sides */
}

Inline-Block

Inline-block elements are a hybrid between block and inline elements. They allow you to set width and height like block elements while still flowing within the text like inline elements. To create an inline-block element, use the display: inline-block; property.

.box {
  display: inline-block; /* Allows width and height */
  width: 200px;
  height: 100px;
  background-color: lightblue;
}

Conflicts

Conflicts in CSS occur when multiple styles apply to the same element, leading to ambiguity about which style should take precedence. Understanding how CSS resolves these conflicts is essential for effective styling.

Specificity

Specificity is a key concept in CSS that determines which styles are applied when multiple rules match the same element. It is calculated based on the types of selectors used in the rule.

.main-heading {
  color: red;
}

h1 {
  color: blue;
}
<h1 class="main-heading">This is a heading</h1>

In this example, the .main-heading class has a higher specificity than the h1 element selector, so the text will be red.

If both selectors have the same specificity, the last one defined in the CSS will take precedence.

h1 {
  color: red;
}

h1 {
  color: blue;
}

Inheritance

Some CSS properties are inherited from parent elements to child elements. This means that if a property is set on a parent element, its child elements will automatically receive that property unless it is overridden.

For example, properties like color, font-family, and line-height are inherited, while properties like margin, padding, and border are not.

Inheritance can be controlled by using the inherit, initial, unset, and revert keywords.

  • inherit: Forces the property to inherit the value from its parent.

  • initial: Sets the property to its default value.

  • unset: Resets the property to its natural value, which is either inherited or initial.

  • revert: Resets the property to the value it would have had if the stylesheet had not changed it.

.parent {
  color: green;
}

.child {
  color: unset;
}

Important Flag

The !important flag can be used to override any other styles applied to an element, regardless of specificity or inheritance. It should be used sparingly, as it can make debugging and maintaining CSS more difficult.

.main-heading {
  color: red !important;
}

Sizing

Sizing in CSS is crucial for defining the dimensions of elements on a web page. It involves understanding how to use different units and properties to achieve the desired layout and responsiveness.

Intrinsic Size

Every HTML element has an intrinsic size, which is determined by its content and the styles applied to it. Understanding how to control and manipulate this size is essential for creating effective layouts in CSS.

For example, an <img> element has a natural size based on the image file while a <div> element has no intrinsic size and will expand to fit its content.

Extrinsic Size

Extrinsic size refers to the size of an element as defined by CSS properties such as width and height.

.element {
  width: 200px;
  height: 100px;
}

A set height can cause content to overflow if there is more content than the element has space to fit inside it.

Percentages

Percentages in CSS are used to define sizes relative to the parent element’s size. This allows for flexible and responsive designs that adapt to different screen sizes.

.element {
  width: 50%; /* 50% of the parent element's width */
  height: 50%; /* 50% of the parent element's height */
}

Overflow

When the content of an element exceeds its defined size, it can lead to overflow. CSS provides several properties to control how overflow is handled:

  • overflow: Specifies how to handle overflow content. Possible values include visible, hidden, scroll, and auto.

  • overflow-x: Controls horizontal overflow.

  • overflow-y: Controls vertical overflow.

.element {
  width: 200px;
  height: 100px;
  overflow: auto; /* Adds scrollbars if content overflows */
}

Min and Max Sizes

CSS allows you to set minimum and maximum sizes for elements using the min-width, max-width, min-height, and max-height properties. This is useful for ensuring that elements do not shrink below a certain size or grow beyond a certain size.

.element {
  min-width: 100px;
  max-width: 500px;
  min-height: 50px;
  max-height: 300px;
}

Layout

Layout in CSS refers to the arrangement of elements on a web page. It involves understanding how to position elements, control their size, and create responsive designs that adapt to different screen sizes and resolutions.

Floats

Floats are a CSS property that allows elements to be taken out of the normal document flow and positioned to the left or right of their containing element. This is often used for text wrapping around images or creating multi-column layouts.

<h1>Float example</h1>

<div class="box">Float</div>

<p>Some text that wraps around the floated element.
   This text will flow around the box that is floated to the left.</p>
.box {
  float: left;
  width: 200px;
  margin: 10px;
}

In the past, floats were commonly used to implement complex page layouts. Since there are newer, better layout techniques available, using floats in this way should be regarded as a legacy technique.

Static

The default positioning scheme where elements are positioned according to the normal flow of the document. They are not affected by top, right, bottom, or left properties.

<h1>Static Positioning</h1>
<div class="static-box">This is a static box.</div>
.static-box {
  position: static;
  background-color: lightblue;
}

Relative

Elements are positioned relative to their normal position in the document flow. The top, right, bottom, and left properties can be used to adjust their position without affecting the layout of surrounding elements.

.static-box {
  position: relative;
  background-color: lightblue;
  top: 20px; /* Moves the box down by 20 pixels */
  left: 20px; /* Moves the box to the right by 20 pixels */
}

With position: relative;, the position of the element is modified after the element has taken its place in the normal flow. This means the element could overlap with other elements on the page.

Absolute

Elements are positioned relative to the nearest positioned ancestor (an ancestor with a position other than static). If no such ancestor exists, they are positioned relative to the initial containing block (usually the viewport).

.static-box {
  position: absolute;
  background-color: lightblue;
  top: 20px; /* Moves the box down by 20 pixels */
  left: 20px; /* Moves the box to the right by 20 pixels */
}

An absolutely positioned element is removed from the normal document flow and does not affect the position of other elements on the page. This can lead to overlapping elements if not managed carefully.

THe use of position: absolute; is very useful for creating overlays, modals, or tooltips that need to appear on top of other content without affecting the layout of the page.

Fixed

Elements are positioned relative to the viewport and do not move when the page is scrolled. They are often used for headers, footers, or sidebars that should remain visible at all times.

.fixed-box {
  position: fixed;
  background-color: lightblue;
  top: 0; /* Fixed to the top of the viewport */
  left: 0; /* Fixed to the left of the viewport */
  width: 100%;
}

Sticky

Elements are positioned based on the user’s scroll position. They behave like relative elements until a certain scroll position is reached, at which point they become fixed.

.sticky-box {
  position: sticky;
  background-color: lightblue;
  top: 0;
}

When the user scrolls down, the sticky element will remain in its position until it reaches the top of the viewport, at which point it will stick there until the user scrolls back up.

Z-Index

The z-index property controls the stacking order of positioned elements. Elements with a higher z-index value will appear in front of those with a lower value. This is particularly useful when you have overlapping elements and want to control which one appears on top.

.box {
  position: absolute;
  background-color: lightblue;
  z-index: 10; /* Will appear above others with a lower z-index */
}

Flexbox

Flexbox, or the Flexible Box Layout, is a CSS layout model that allows for the design of complex layouts with ease. It provides a more efficient way to lay out, align, and distribute space among items in a container, even when their size is unknown or dynamic. Some common scenarios where Flexbox is particularly useful include:

  • Aligning items in a row or column

  • Distributing space between items

  • Centering items both vertically and horizontally

  • Creating responsive layouts that adapt to different screen sizes

Flexbox Case-Study

  1. Create an HTML page with a header and three articles

    <header>
  <h1>Sample flexbox example</h1>
</header>
<section>
  <article>
    <h2>First article</h2>
    <p>Content…</p>
  </article>
  <article>
    <h2>Second article</h2>
    <p>Content…</p>
  </article>
  <article>
    <h2>Third article</h2>
    <p>Content…</p>
  </article>
</section>

  2. Use CSS to apply some basic styling

    body {
  font-family: sans-serif;
  margin: 0;
}
header {
  background: purple;
  height: 100px;
}
h1 {
  text-align: center;
  color: white;
  line-height: 100px;
  margin: 0;
}
article {
  padding: 10px;
  margin: 10px;
  background: aqua;
}

Flex Container

In Flexbox, a flex container is an element that has its display property set to flex or inline-flex. This container will hold the flex items (the child elements) and control their layout.

Flex Container

  1. Use CSS to make the section a flex container

    section {
  display: flex;
}

By defining the section as a flex container, its child elements (the articles) became flex items. By default, this arranges the articles into a single row and the width of each article is determined by its content.

Flex Direction

The flex-direction property specifies the direction in which the flex items are placed in the flex container. The default value is row, which arranges the items horizontally. Other possible values include column, row-reverse, and column-reverse.

section {
  display: flex;
  flex-direction: column;
}

Wrapping

The flex-wrap property controls whether the flex items should wrap onto multiple lines if they cannot fit in a single line. The default value is nowrap, which means all items will be on one line. Other values include wrap and wrap-reverse.

Flexible Sizing

The flex property allows you to specify how much a flex item should grow or shrink relative to the other items in the flex container. If all flex items have the same flex value, they will take up equal space in the container. If one item has a larger flex value, it will take up proportionally more space than the others.

Flexible Sizing

  1. Use the flex property to distribute the available space equally among all the articles

    article {
  flex: 1;
}

  2. Use a selector to cause the thrid article to take up twice as much space as the others

    article:nth-child(3) {
  flex: 2;
}

A minimum size can be set for flex items that will be applied before the remaining space is distributed.

article {
  flex: 1 100px;
}

Alignment

Flexbox provides several properties for aligning items within the flex container. The justify-content property controls the alignment of items along the main axis (horizontal by default), while the align-items property controls the alignment along the cross axis (vertical by default).

Flexbox Alignment

  1. Create an HTML page with a collection of buttons

    <div>
  <button>One</button>
  <button>Two</button>
  <button>Three</button>
  <button>Four</button>
  <button>Five</button>
</div>

  2. Define the <div> as a flex container and add some styling to help visualize the alignment of the buttons

    div {
  display: flex;
  height: 100px;
  border: 1px solid black;
}

  3. Add a justify-content property to align the buttons along the main axis

    justify-content: space-around;

  4. Add a align-items property to align the buttons along the cross axis

    align-items: center;

You can override the default alignment of individual items using the align-self property. This allows you to align a specific item differently from the others in the flex container.

button:first-child {
  align-self: flex-end;
}

CSS Grid Layout

CSS Grid Layout is another modern layout system that allows developers to create complex, responsive web designs. It provides a two-dimensional grid-based layout system, enabling the arrangement of elements in rows and columns. This makes it particularly useful for creating layouts that require precise control over the placement and alignment of elements.

Grid Case-Study

  1. Create an HTML page with <div> container and a number of child <div> elements

    <div class="container">
  <div>One</div>
  <div>Two</div>
  <div>Three</div>
  <div>Four</div>
  <div>Five</div>
  <div>Six</div>
  <div>Seven</div>
</div>

  2. Use CSS to apply some basic styling to the child elements

    .container > div {
  border-radius: 5px;
  padding: 10px;
  background-color: rgb(207 232 220);
  border: 2px solid rgb(79 185 227);
}

Grid Container

Using grid payout is similar to using flex layout in that the parent element can be defined as a grid container causing the child elements will behave as grid items. By default, using display: grid will create a single column layout.

.container {
    display: grid;
}

Grid Template Columns

To define the number of columns in a grid layout, the grid-template-columns property is used. This property allows you to specify the size of each column in the grid.

.container {
  display: grid;
  grid-template-columns: 200px 100px 100px;
}

Instead of providing fixed pixel values, you can also use the fr unit, which stands for "fractional unit". The fr unit allows you to distribute available space in the grid container among the columns.

.container {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
}

Gaps

The gap property is used to define the space between grid items. It can be applied to both rows and columns, allowing for consistent spacing in the grid layout.

.container {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  gap: 10px;
}

CSS Preprocessors

CSS preprocessors are scripting languages that extend the capabilities of CSS, allowing developers to write more maintainable and efficient stylesheets. They introduce features like variables, nesting, mixins, and functions, which help in organizing and reusing styles across a project. Preprocessors compile down to standard CSS, making them compatible with all browsers.

Sass

Sass (Syntactically Awesome Style Sheets) is a popular CSS preprocessor and uses files with the .scss or .sass extension. A command-line tool ca be used to compile Sass files into standard CSS files.

sass input.scss output.css

Variables

Variables in Sass allow you to store values that can be reused throughout your stylesheets. This is particularly useful for maintaining consistency in colors, fonts, and other design elements.

$primary-color: #3498db;
$font-stack: 'Helvetica Neue', sans-serif;

body {
  font-family: $font-stack;
  color: $primary-color;
}

Mixins

Mixins in Sass allow you to create reusable blocks of styles that can be included in multiple selectors. This helps reduce code duplication and makes it easier to maintain styles.

@mixin rounded-corners($radius) {
  border-radius: $radius;
}
.box {
  @include rounded-corners(10px);
  background-color: $primary-color;
  padding: 20px;
}
.box-large {
  @include rounded-corners(20px);
  background-color: darken($primary-color, 10%);
}

Less

Less is another popular CSS preprocessor that extends CSS with features like variables, nesting, and mixins. It uses files with the .less extension and can be compiled into standard CSS using a command-line tool or build process.

lessc input.less output.css

Variables

Variables in Less work similarly to Sass, allowing you to define reusable values for colors, fonts, and other styles.

@primary-color: #3498db;
@font-stack: 'Helvetica Neue', sans-serif;

body {
  font-family: @font-stack;
  color: @primary-color;
}

Mixins

Mixins in Less allow you to create reusable styles that can be included in multiple selectors, similar to Sass.

.rounded-corners(@radius) {
  border-radius: @radius;
}
.box {
  .rounded-corners(10px);
  background-color: @primary-color;
  padding: 20px;
}

CSS Frameworks

CSS frameworks are pre-prepared libraries that are meant to be used as a base for starting a project. They provide a set of CSS classes and components that can be used to quickly build responsive and visually appealing web pages. Frameworks often include styles for typography, forms, buttons, navigation, and other common UI elements.

Bootstrap

Bootstrap is one of the most popular CSS frameworks, developed by Twitter. It provides a comprehensive set of styles and components that help developers create responsive and mobile-first web applications. Bootstrap includes a grid system, pre-styled components, and JavaScript plugins for interactivity.

Bootstrap’s grid system allows for flexible layouts that adapt to different screen sizes. It uses a series of containers, rows, and columns to structure content. The framework also includes utility classes for spacing, alignment, and visibility.

Tailwind CSS

Tailwind CSS is a utility-first CSS framework that provides low-level utility classes to build custom designs without leaving your HTML. Instead of providing pre-designed components, Tailwind allows developers to compose styles directly in their markup, promoting a more modular and reusable approach to styling.

Tailwind’s utility classes cover a wide range of CSS properties, including layout, typography, colors, and more. This approach enables developers to create unique designs while maintaining consistency across their projects.
