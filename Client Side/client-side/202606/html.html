HTML

Introduction

HTML (HyperText Markup Language) is used to define the meaning and structure of web content.

  • Hypertext: Content that allows for a reader to navigate to related content through embedded hyperlinks.

  • Markup language: A text-encoding system which specifies the structure and formatting of a document.

Many tools exist that can validate HTML documents. These tools can check for errors in the markup and ensure that a document conforms to the HTML standards. One such tool can be found at https://validator.w3.org

The World Wide Web Consortium (W3C) is the main international standards organization for the World Wide Web. The W3C has published several versions of HTML, including HTML 4.01 and XHTML 1.0. However, the Web Hypertext Application Technology Working Group (WHATWG) was formed in 2004 in response to the slow development of W3C standards. The WHATWG steering group includes many industry leaders such as Apple, Google, Mozilla, and Microsoft. IN 2019, the W3C announced that WHATWG would be the sole publisher of the HTML and DOM standards. The HTML "living standard" can be found at https://html.spec.whatwg.org

XHTML is a term that was historically used to describe HTML documents written to conform to XML’s stricter syntax rules. In 2002, the World Wide Web Consortium (W3C) recommended that developers should migrate from HTML 4.01 to XHTML 1.0. However, this effort did not gain traction, and the W3C eventually abandoned XHTML in favor of HTML5.

Here is an example of a simple HTML document:

<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width">
    <title>Simple page</title>
  </head>
  <body>
    <p>This is a paragraph of text</p>
  </body>
</html>

Doctype

When an HTML page is loaded, the web browser must determine how to interpret the document. This is done by using a DOCTYPE declaration, which is the first line of an HTML document. The simplest doctype and the one recommended by current HTML standards is:

<!doctype html>

This doctype will ensure the web browser uses "full standards mode". Other doctypes (or a missing doctype) can cause the web browser to use "quirks mode" or "limited quirks mode". Quirks mode is a compatibility mode that allows older web pages to be displayed correctly, even if they do not conform to modern standards.

Elements and Tags

HTML consists of a series of elements, which you use to enclose, wrap, or mark up different parts of content to make it appear or act in a certain way. An element is identified by a tag, which is a keyword surrounded by angle brackets. Tags typically come in pairs, with an opening tag and a closing tag. The closing tag has a forward slash before the tag name.

<title>My Web Page</title>

Element names are not case-sensitive. However, the convention and recommended practice is to write tags exclusively in lowercase.

Some elements do not contain any content and are self-closing. These elements are called "void elements" and do not require a closing tag.

<br>

The complete list of void elements in HTML5 is: area, base, br, col, command, embed, hr, img, input, keygen, link, meta, param, source, track, and wbr.

Attributes

Attributes are used to provide additional information about an element. They are always specified in the opening tag and consist of a name and a value. The name and value are separated by an equals sign, and the value is typically enclosed in quotes.

<img src="pic.png" alt="My Picture">

HTML5 does allow for attribute values to be specified using single quotes or no quotes at all (with some limitations):

<img src='pic.png' alt='My Picture'>
<img src=pic.png alt=My Picture>

However, it is recommended to always use double quotes for consistency and readability.

Some attributes are considered to be "boolean attributes". These attributes do not require a value and are either present or absent.

<input type="checkbox" checked>

It is also acceptable to include a value that matches the attribute name but this is ignored by the parser.

<input type="checkbox" checked="checked">

HTML Element

The <html> element acts as the root element of the document and should include a lang attribute to identify the primary language of the document.

The lang attribute value made of hyphen-separated language subtags, where each subtag indicates a certain property of the language:

  • The first subtag is the primary language subtag, which is a two-letter code defined by ISO 639-1.

  • The second subtag is the optional subtag that indicates the region or country, which is a two-letter code defined by ISO 3166-1 alpha-2.

  • The third subtag is the optional variant subtag, which is a string that indicates a specific dialect or variation of the language.

Head Element

The <head> element acts as a container for elements that belong to the HTML document but don’t directly define visible content. This includes things like keywords and a page description that you want to appear in search results, CSS to style the content, and more.

Meta Elements

HTML <meta> elements are used to specify metadata about the HTML document. Metadata is data that describes other data. Two <meta> elements that are typically always used include:

  • charset - This specifies the character encoding for the HTML document. The most common value is utf-8, which supports a wide range of characters from different languages.

  • viewport - This specifies how the document should be displayed on different devices. The most common value is width=device-width, which sets the width of the viewport to the width of the device. This is important for responsive design, where the layout of the page changes based on the size of the screen.

Title Element

The <title> element is used to specify the title of the HTML document. The title is displayed in the browser’s title bar or tab and is also used by search engines to identify the page. The title should be descriptive and concise.

For a public website, a title between 55 and 65 characters long is considered ideal for SEO purposes. Titles longer than 65 characters will tend to be truncated when displayed in search results.

Body Element

The <body> element is used to define the visible content of the HTML document. This includes text, images, links, and other elements that are displayed on the page.

Whitespace

Whitespace in HTML is used to separate elements and make the code more readable but the browser will ignore extra whitespace and treat it as a single space.

The following two snippets of HTML would produce identical results when rendered in a web browser:

<p>This is some text.</p>
<p>This
    is
        some text.</p>

Comments

HTML comments are used to insert notes or explanations in the code that will not be displayed in the browser. Comments are enclosed in <!-- and -→.

<p>This is some text.</p>
<!-- This is a comment -->

Although HTML comments are ignored by the browser, they can still be seen in the page source. Therefore, it is not recommended to use comments to hide sensitive information.

Text

Most structured text consists of headings, paragraphs, and lists. This is true not just for HTML but for things like newspapers, textbooks, and magazines. These elements may be styled differently, but they are still the same elements.

Paragraphs

In HTML, each paragraph should be within a <p> element:

<p>This is some text.</p>

How the text is displayed depends on the CSS styles applied to the <p> element. By default, browsers will display paragraphs with a blank line before and after them. This is not part of the HTML markup but rather a default style applied by the browser.

A <p> element is a block-level element which means that it takes the full-width of its parent. A <p> element can contain inline elements such as links and images, but it cannot contain another block-level elements such as a <div>, an <h1>, or another <p>.

Headings

Heading help to make a web page more readable by breaking up the text into sections. They also help search engines and screen readers to understand the structure of a page and its content.

<h1>My Topic</h1>
<p>This is some text.</p>

Six heading elements are defined in HTML: <h1>, <h2>, <h3>, <h4>, <h5>, and <h6>. Each element represents a different level of content in the document with <h1> representing the top or main heading.

Like with <p> elements, how a specific heading appears (font, size, etc.) will be affected by any applied CSS or else the browser will use its own default style.

Headings are also block-level elements and therefore cannot contain other block-level elements.

Some general best practices for headings include:

  • Use only one <h1> element per page.

  • Use headings in the correct numerical order to create a logical hierarchy of content.

  • Try to use no more than three levels of headings on a page.

Emphasis and Importance

Emphasis and importance are used to indicate that a piece of text is important or should be emphasized. In HTML, this is done using the <em> and <strong> inline elements.

<p><em>This</em> is some <strong>important</strong> text.</p>

By default, the text inside an <em> element is displayed in italics, while the text inside a <strong> element is displayed in bold but both are semantic elements.

A semantic element is used to convey meaning about the content it contains and not dictate presentation style. This is important for accessibility and search engine optimization (SEO). For example, screen readers will read the text inside an <em> element with emphasis, while search engines may use the text inside a <strong> element to determine the importance of the content.

In HTML5, elements that are not semantic, such as <b> and <i> should be avoided in favor of semantic elements.

Lists

HTML defines three different types of lists: ordered lists, unordered lists, and description lists. Each type of list has its own specific markup.

Unordered Lists

An unordered list is used to create a list of items where the order does not matter. In HTML, an unordered list is created using the <ul> element, and each item in the list is defined using the <li> element.

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

The default bullet style is a solid circle, but this can be changed using CSS.

Ordered Lists

An ordered list is used to create a list of items where the order does matter. In HTML, an ordered list is created using the <ol> element, and each item in the list is defined using the <li> element.

<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>

The default numbering style is Arabic numerals (1, 2, 3), but this can be changed using CSS.

Unordered and ordered lists can be nested inside each other to create sublists. This is done by placing one list inside another list item.

<ul>
  <li>Item 1
    <ul>
      <li>Subitem 1</li>
      <li>Subitem 2</li>
    </ul>
  </li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

Description Lists

A description list is used to create a list of items with associated descriptions such as terms and definitions, or questions and answers. In HTML, a description list is created using the <dl> element, and each item in the list is defined using the <dt> and <dd> elements.

<dl>
  <dt>Term 1</dt>
  <dd>Description 1</dd>
  <dt>Term 2</dt>
  <dd>Description 2</dd>
</dl>

The <dt> element is used to define the term, while the <dd> element is used to define the description. Description lists can also be nested inside each other to create sublists.

Links

Hyperlinks allow you to link documents to other documents or to link to a specific part of a document. A basic link is created using the <a> tag, with the href attribute specifying the URL of the page to link to. The text between the opening and closing <a> tags is what will be displayed as the clickable link.

<p>
  This is a link to the <a href="https://www.w3.org">W3C homepage</a>.
</p>

The anchor element can also be used to turn a block-level element into a link.

<a href="https://www.w3.org">
  <h1>W3C</h1>
</a>
<p>World Wide Web Consortium</p>

Title Attribute

The title attribute can be added to the <a> tag to provide additional information about the link. This information is displayed as a tooltip when the user hovers over the link.

<a href="https://www.w3.org" title="World Wide Web Consortium">
  W3C homepage
</a>

URLs and Paths

The href attribute can contain absolute or relative URLs. An absolute URL includes the full path to the resource, while a relative URL is relative to the current document’s location.

<a href="https://www.w3.org">Absolute URL</a>
<a href="docs/page.html">Relative URL</a>
<a href="../info/about.html">Another relative URL</a>

If a path starts with a slash, The web browser will use the current page’s base URL to create an absolute path.

<a href="/info/about.html">About Us</a>

If the above link was on a page located at https://www.mysite.com/app/page.html, the link would take the user to https://www.mysite.com/info/about.html

Using a root-relative path (/) can produce unexpected results when viewing the content on a local file system. It is recommended to use relative paths instead.

Document Fragments

You can link to a specific part of a document by using a fragment identifier. This is done by appending a # followed by the ID of the element you want to link to.

<h2 id="mailing-address">Mailing address</h2>
<p>
  Contact us via <a href="contact.html#mailing-address">mail</a>.
</p>

Target Attribute

By default, when a link is clicked, the browser will navigate to the linked page in the same window or tab. However, you can change this behavior using the target attribute of the <a> tag.

<a href="https://www.w3.org" target="_blank">W3C</a>

When a link will open a new tab, it is a common practice to provide the user with a visual cue such as an icon next to the link text.

Images

To include an image in an HTML document, the <img> element is used. The src attribute specifies the path to the image file, and the alt attribute provides alternative text for the image if it cannot be displayed.

<img src="path/to/image.jpg" alt="Description of image">

The <img> element is a void element (self-closing tag) and does not require a closing tag.

Width and Height

Elements like <img> and <video> are referred to as replaced elements. This is because the element’s content and size are defined by an external resource and not by the contents of the element itself. This means that the content of the page may shift around when the image or video loads, as the browser does not know the size of the element until the resource is loaded.

To prevent this, the width and height attributes can be used to specify the size of the image or video. This allows the browser to reserve space for the element before it is loaded.

<img src="path/to/image.jpg"
     alt="Description of image"
     width="300"
     height="200">

The width and height are specified in pixels, and the aspect ratio of the image will be maintained. If the image is larger than the specified size, it will be scaled down to fit. If it is smaller, it will be displayed at its original size.

The width and height attributes should be used to specify the actual size of an image, and should not be used to resize an image for display. If you do need to alter an image’s size, you should modify the image itself or use CSS if necessary.

Image Formats

The HTML standard does not specify which image formats are supported. Common formats such as jpeg, png, and gif are universally supported but support for other newer formats may vary among different web browsers.

The <picture> element can be used to specify multiple image sources for different formats. This allows the browser to choose the best format for the user’s device and browser.

<picture>
  <source srcset="diagram.svg" type="image/svg+xml">
  <source srcset="diagram.webp" type="image/webp">
  <source srcset="diagram.jpg" type="image/jpeg">
  <img src="diagram.jpg" alt="Description of image">
</picture>

Image Link

An <img> element can be used as a link by wrapping it in an <a> tag.

<a href="https://www.example.com">
  <img src="path/to/image.jpg" alt="Description of image">
</a>

Tables

A table is a structured arrangement of data, typically organized in rows and columns. Tables are used to present information in a clear and concise manner, making it easier for users to read and understand the data. In HTML, tables are created using the <table> element, along with other related elements such as <tr> (table row), <th> (table header), and <td> (table data).

<table>
  <tr>
    <th>Header 1</th>
    <th>Header 2</th>
    <th>Header 3</th>
  </tr>
  <tr>
    <td>Row 1, Cell 1</td>
    <td>Row 1, Cell 2</td>
    <td>Row 1, Cell 3</td>
  </tr>
  <tr>
    <td>Row 2, Cell 1</td>
    <td>Row 2, Cell 2</td>
    <td>Row 2, Cell 3</td>
  </tr>

Tables should be used for tabular data only. Do not use tables for layout purposes, as this can lead to accessibility issues and make the content difficult to read on different devices.

Column Headers

The <th> element should be used to identify column headers both visually and semantically. Column headers are bold and centered by default but this can be changed via CSS.

Spanning Rows and Columns

The colspan and rowspan attributes can be used to merge multiple cells into one. The colspan attribute specifies the number of columns a cell should span, while the rowspan attribute specifies the number of rows a cell should span.

<table>
  <tr>
    <th colspan="2">Header 1</th>
    <th>Header 2</th>
  </tr>
  <tr>
    <td rowspan="2">Row 1, Cell 1</td>
    <td>Row 1, Cell 2</td>
    <td>Row 1, Cell 3</td>
  </tr>
  <tr>
    <td>Row 2, Cell 2</td>
    <td>Row 2, Cell 3</td>
  </tr>
</table>

Sections

The <thead>, <tbody>, and <tfoot> elements can be used to group the header, body, and footer sections of a table. This can help with styling and accessibility, as well as improve the performance of the table when rendering large datasets.

<table>
  <thead>
    <tr>
      <th>Header 1</th>
      <th>Header 2</th>
      <th>Header 3</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Row 1, Cell 1</td>
      <td>Row 1, Cell 2</td>
      <td>Row 1, Cell 3</td>
    </tr>
    <tr>
      <td>Row 2, Cell 1</td>
      <td>Row 2, Cell 2</td>
      <td>Row 2, Cell 3</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="3">Footer</td>
    </tr>
  </tfoot>
</table>

Caption

The <caption> element can be used to provide a title or description for the table. This is typically displayed above the table and can help users understand the purpose of the table.

<table>
  <caption>Table Caption</caption>
  <tr>
    <th>Header 1</th>
    <th>Header 2</th>
    <th>Header 3</th>
  </tr>
  <tr>
    <td>Row 1, Cell 1</td>
    <td>Row 1, Cell 2</td>
    <td>Row 1, Cell 3</td>
  </tr>
</table>

Forms

HTML forms provide a way for users to manipulate a user interface (UI) and input data.

Form Element

Forms are created using the <form> element, which can contain various input elements such as text fields, checkboxes, radio buttons, and submit buttons.

The <form> element can also include attributes such as action and method, which specify the URL to send the form data to and the HTTP method to use (GET or POST), respectively.

<form action="/login" method="POST">
</form>

A GET action will append the form data to the URL as query parameters, while a POST action will send the data in the request body. GET should typically be used for idempotent requests (performing a search), while POST should be used for non-idempotent requests (charging a credit card).

Input Elements

The <input> element is used to create various types of input fields, such as text fields, checkboxes, radio buttons, and file uploads.

<input type="text" name="username" placeholder="Enter your username">
<input type="password" name="password" placeholder="Enter your password">

  • type: Specifies the type of input field to create. Common types include text, password, email, number, checkbox, radio, file, and submit.

  • name: Specifies the name of the input field, which is used to identify the field when the form is submitted.

  • placeholder: Provides a short hint that describes the expected value of the input field. This text is displayed inside the input field when it is empty.

  • value: Specifies the default value of the input field. This is the value that will be submitted with the form if the user does not change it.

  • required: Specifies that the input field must be filled out before the form can be submitted. This is a boolean attribute, so it does not require a value.

    <input type="text" name="username" required>

Label Elements

<label> elements provide a way to associate a text label with an input field. This improves accessibility and usability.

<label for="username">Username:</label>
<input type="text" id="username" name="username">

The for attribute of the <label> element should match the id attribute of the associated input field. This creates a relationship between the label and the input field, allowing screen readers to announce the label when the input field is focused.

Button Element

The <button> element is used to create a clickable button that can be used to submit a form or trigger a JavaScript function.

<form action="/login" method="POST">
  ...
  <button type="submit">Login</button>
</form>

When included inside a form, the <button> element will submit the form by default. To prevent this behavior, you can set the type attribute to button.

Radio Buttons

Radio buttons are used to allow users to select one option from a group of options. They are created using the <input> element with the type attribute set to radio.

<input type="radio" name="pet" id="dog" value="dog" checked>
<label for="dog">Dog</label>
<input type="radio" name="pet" id="cat" value="cat">
<label for="cat">Cat</label>

The name attribute of the radio buttons should be the same for all options in the group. This allows the browser to treat them as a single group, ensuring that only one option can be selected at a time.

You must include a value attribute for each radio button. This value will be submitted with the form when the user selects that option.

Checkboxes

Checkboxes are similar to radio buttons, but they do not represent a mutually exclusive set of options. They are created using the <input> element with the type attribute set to checkbox.

<input type="checkbox" name="reading" id="reading">
<label for="reading">Reading</label>
<input type="checkbox" name="sports" id="sports">
<label for="sports">Sports</label>
<input type="checkbox" name="music" id="music">
<label for="music">Music</label>

On submission, each value is submitted with a value of on if the checkbox was checked (e.g., reading=on) or not submitted at all if it was unchecked.

Fieldset

A <fieldset> element can be used to group related input elements within a form. This improves accessibility and usability by visually separating different sections of the form.

<fieldset>
  <legend>Hobbies</legend>
  <input type="checkbox" name="reading" id="reading">
  <label for="reading">Reading</label>
  <input type="checkbox" name="sports" id="sports">
  <label for="sports">Sports</label>
  <input type="checkbox" name="music" id="music">
  <label for="music">Music</label>
</fieldset>

Dropdown Menus

A dropdown menu is created using the <select> element, which contains one or more <option> elements. The <option> elements represent the individual options in the dropdown menu.

<label for="pet">Choose a pet:</label>
<select name="pet" id="pet">
  <option value="">--Please choose an option--</option>
  <option value="dog">Dog</option>
  <option value="cat">Cat</option>
  <option value="fish">Fish</option>
</select>

Textarea

A <textarea> element is used to create a multi-line text input field. It is typically used for longer text inputs, such as comments or messages.

<label for="comments">Other comments:</label>
<textarea id="comments" name="comments" rows="5" cols="40"></textarea>

Form Validation

Some basic client-side validation can be provided by the browser by using the required attribute on input elements. This will prevent the form from being submitted if the required fields are not filled out. Specific types of input fields, such as email and number, will also provide built-in validation for the format of the input.

Oftentimes, you may want to provide more customized validation. This can be done using JavaScript to check the values of the input fields before the form is submitted. If the validation fails, you can prevent the form from being submitted and display an error message to the user.

Client-side validation can provide an improved user experience but it should only be used as a supplement to server-side validation, not as a replacement. It is critical to always validate and sanitize user input on the server side to prevent security vulnerabilities such as SQL injection and cross-site scripting (XSS).

Document Structure

HTML includes a number of block level elements to define areas of a page with a specific semantic meaning. Assistive technologies like screen readers can recognize those elements and help with tasks like "find the main navigation", or "find the main content" and search engines can index a site more effectively when they have a better understanding of the document structure.

Main Element

The <main> element is used to identify the main content of a document. This is the content that is unique to the page and not repeated on other pages, such as the main article or blog post. The <main> element should only be used once per page and should not be nested within other elements like <header>, <footer>, or <nav>.

<body>
  <main>
    <h1>Main Content</h1>
    <p>This is the main content of the page.</p>
  </main>
</body>

Article Element

The <article> element is used to identify a self-contained piece of content that could be distributed and reused independently. This could be a blog post, news article, or any other type of content that can stand on its own. The <article> element can be nested within other elements like <main>, <section>, or <aside>, but should not be used as a wrapper for the entire page.

<main>
  <h1>Main Content</h1>
  <p>This is the main content of the page.</p>
  <article>
    <h2>Article Title</h2>
    <p>This is the content of the article.</p>
  </article>
</main>

Section Element

The <section> element is used to identify a thematic grouping of content within a document. This could be a section of a blog post, a chapter in a book, or any other type of content that is related to a specific topic. The <section> element can contain headings, paragraphs, images, and other elements.

<article>
  <h2>Article Title</h2>
  <p>This is the content of the article.</p>
  <section>
    <h3>Section Title</h3>
    <p>This is the content of a section.</p>
  </section>
</article>

Aside Element

The <aside> element is used to identify content that is related to the main content of the page but is not essential to its meaning. This could be a sidebar, a related article, or any other type of content that provides additional context or information.

<main>
  <h1>Main Content</h1>
  <p>This is the main content of the page.</p>
  <aside>
    <h2>Related Articles</h2>
    <ul>
      <li><a href="#">Related Article 1</a></li>
      <li><a href="#">Related Article 2</a></li>
    </ul>
  </aside>
</main>

Header Element

The <header> element is used to identify the header section of a document or a section. This could include the title, logo, navigation links, and other introductory content. The <header> element can be used within other elements like <main>, <article>, or <section>.

<body>
  <header>
    <img src="logo.png" alt="Logo">
  </header>
  <main>
    <h1>Main Content</h1>
    <p>This is the main content of the page.</p>
  </main>
</body>

Nav Element

The <nav> element is used to identify a section of navigation links within a document. This could include the main navigation menu, footer links, or any other type of navigation. The <nav> element should only be used for navigation links and should not be used for other types of content.

<header>
  <img src="logo.png" alt="Logo">
  <nav>
    <ul>
      <li><a href="#">Home</a></li>
      <li><a href="#">About</a></li>
      <li><a href="#">Contact</a></li>
    </ul>
  </nav>
</header>

Footer Element

The <footer> element is used to identify the footer section of a document or a section. This could include copyright information, contact details, and other related content. The <footer> element can be used within other elements like <main>, <article>, or <section>.

<body>
  <header>...</header>
  <main>...</main>
  <footer>
    <p>&copy; 2025 My Website</p>
  </footer>
</body>

Divs and Spans

The <div> and <span> elements are generic container elements that can be used to group content together. The <div> element is a block-level element, while the <span> element is an inline element. These elements do not have any semantic meaning on their own but can be styled with CSS or manipulated with JavaScript.

<div class="shopping-cart">
  <h2>Shopping cart</h2>
  <ul>
    <li>...</li>
  </ul>
  <p>Total cost: $237.89</p>
</div>

The <div> and <span> elements are often used as hooks for CSS styling or JavaScript manipulation. They should be used sparingly and only when there is no other semantic element that can be used instead.

Line Breaks

A <br> element can be used to create a line break within a block of text. This is useful for formatting text or creating space between elements. The <br> element is a void element, meaning it does not require a closing tag.

<p>
  This is a line of text.<br>
  This is another line of text.
</p>

Horizontal Rules

An <hr> element can be used to create a horizontal line that separates content. This is useful for visually dividing sections of a document. The <hr> element is also a void element and does not require a closing tag.

<p>This is some text.</p>
<hr>
<p>This is some more text.</p>
