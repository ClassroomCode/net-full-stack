JavaScript

Introduction

Every modern web browser includes a JavaScript engine that can interpret and execute JavaScript. Code executing in the browser can manipulate the Document Object Model (DOM), which represents the structure of a web page, allowing developers to create dynamic and interactive user interfaces.

Web browsers also now include the ability to execute WebAssembly, a binary instruction format that allows for high-performance execution of code written in languages like C, C++, and Rust. This enables developers to run computationally intensive tasks in the browser, complementing JavaScript’s capabilities.

Adding to a Web Page

To add JavaScript to a web page, you can use the <script> tag. This tag can be placed in the <head> or <body> section of your HTML document. The src attribute is used to link to an external JavaScript file, while inline scripts can be written directly within the <script> tags.

<script src="script.js"></script>
<script>
  console.log('Hello, World!');
</script>

Order of Execution

By default, JavaScript is executed in the order it appears in the HTML document. If a script is placed in the <head>, it will run before the DOM is fully loaded, which can lead to issues if the script tries to access elements that are not yet available. To ensure that scripts run after the DOM is ready, it was common for scripts to be placed at the end of the <body>.

Defer and Async

To control the loading and execution of scripts, you can use the defer and async attributes in the <script> tag.

<script src="script.js" defer></script>
<script src="script.js" async></script>

The defer attribute ensures that the script is executed after the HTML document has been fully parsed, while the async attribute allows the script to be executed as soon as it is downloaded, without blocking the parsing of the document.

Using defer is generally recommended for scripts that manipulate the DOM, as it ensures that the DOM is fully loaded before the script runs. The async attribute is useful for scripts that do not depend on the DOM or other scripts, such as analytics or advertising scripts.

With the availability of the defer attribute, it is now common practice to place all scripts in the <head> section of the document, allowing for better organization and separation of concerns.

Variables

In JavaSctipt, variables are used to store data values. They can be declared using const, let, or var. The choice of declaration affects the scope and mutability of the variable.

Using var is generally discouraged in modern JavaScript due to its function scope and potential for hoisting issues. Instead, let and const are preferred for block-scoped variables, which help avoid unintended side effects.

Constants

Using the keyword const is recommended for variables that will not be reassigned.

  • You must initialize a const variable at the time of declaration

  • A constant cannot be reassigned later

const pi = 3.14159;
pi = 3.14; // This will produce an error because PI is a constant

Mutable Variables

For variables that may need to be reassigned, you can use let. A variable declared with let does not need to be given an initial value.

let count;
count = 1;

It is recommended to use const by default and only use let when mutability is required. This helps in writing more predictable and maintainable code.

Naming Conventions

When naming variables, it is important to follow consistent naming conventions to improve code readability and maintainability. Common conventions include:

  • Using camelCase for variable names (e.g., userName, totalCount)

  • Using descriptive names that indicate the purpose of the variable (e.g., isLoggedIn, maxRetries)

  • Avoiding single-letter variable names, except for loop counters (e.g., i, j)

Variable Types

In JavaScript, variables can hold different types of data.

Numbers

Numbers in JavaScript can be integers or floating-point values. They are represented as double-precision 64-bit binary format IEEE 754 values.

Strings

Strings are sequences of characters (UTF-16) used to represent text. They can be defined using single quotes, double quotes, or backticks (template literals).

let message = "Hello, World!";
let greeting = 'Hello, World!';
let template = `Hello, ${userName}!`;

Booleans

Booleans represent a logical entity and can have two values: true or false. They are often used in conditional statements to control the flow of the program.

let isActive = true;
let isComplete = false;

Objects

Objects are collections of key-value pairs, where each key is a string (or Symbol) and the value can be of any type. Objects are defined using curly braces.

let user = {
  name: "Alice",
  age: 30,
  isActive: true,
  address: {
    street: "123 Main St",
    city: "Anytown"
  }
};

Dynamic Typing

JavaScript is a dynamically typed language, meaning that variables can hold values of any type and can change types at runtime. This flexibility allows for rapid development but can also lead to unexpected behavior if not managed carefully.

let value = 42;
value = "Now I'm a string";
value = true;
value = [1, 2, 3];
value = { key: "value" };

Dynamic typing can lead to runtime errors if a variable is used in a way that is incompatible with its current type. It is important to validate and check types when necessary to avoid such issues.

if (typeof value === "number") {
  value = value * 2;
}

Equality

In JavaScript, there are two types of equality comparison: strict equality (===) and loose equality (==). Strict equality checks both the value and the type, while loose equality performs type coercion if the types do not match.

let a = 5;
let b = "5";
console.log(a === b); // false (strict equality, different types)
console.log(a == b); // true (loose equality, type coercion)

null and undefined

In JavaScript, null and undefined are two distinct types that represent the absence of a value.

  • null is an intentional absence of value. It must be explicitly set via code.

    let emptyValue = null;

  • undefined indicates that a variable has been declared but has not yet been assigned a value.

    let uninitializedValue;

For equality, null and undefined are loosely equal (==) but not strictly equal (===).

Conditionals

Conditionals in programming allow you to execute different code paths based on certain conditions. They are essential for controlling the flow of your program and making decisions.

If Statements

If statements evaluate a condition and execute a block of code if the condition is true. They can also include an optional else block to execute code when the condition is false.

if (condition) {
  // Code to execute if condition is true
} else {
  // Code to execute if condition is false
}

Switch Statements

Switch statements allow you to evaluate an expression and execute different blocks of code based on the value of that expression. They are useful for handling multiple conditions in a more organized way than using multiple if statements.

switch (expression) {
  case value1:
    // Code to execute if expression equals value1
    break;
  case value2:
    // Code to execute if expression equals value2
    break;
  default:
    // Code to execute if no cases match
}

Although the break statement is optional, it is generally recommended to use it to prevent fall-through behavior, where multiple cases could execute unintentionally.

Ternary Operator

The ternary operator is a shorthand way to write an if-else statement. It takes three operands: a condition, a value if the condition is true, and a value if the condition is false.

const result = condition ? valueIfTrue : valueIfFalse;

Loops

Loops are fundamental programming constructs that allow you to execute a block of code repeatedly based on a condition. They are essential for tasks that require iteration, such as processing arrays, generating sequences, or performing repetitive calculations.

For Loop

A for loop is used to iterate over a sequence (like an array or a string) or to repeat a block of code a specific number of times. It consists of three parts: initialization, condition, and increment/decrement.

for (let i = 0; i < 10; i++) {
  console.log(i); // Prints numbers from 0 to 9
}

While Loop

A while loop continues to execute a block of code as long as a specified condition is true. It is useful when the number of iterations is not known beforehand.

let i = 0;
while (i < 10) {
  console.log(i); // Prints numbers from 0 to 9
  i++;
}

Do-While Loop

A do-while loop is similar to a while loop, but it guarantees that the block of code will be executed at least once before checking the condition. This is useful when you want to ensure that the code runs before evaluating the condition.

let i = 0;
do {
  console.log(i); // Prints numbers from 0 to 9
  i++;
} while (i < 10);

For…​of Loop

The for…​of loop is used to iterate over iterable objects like arrays, strings, and other collections. It provides a simpler syntax for iterating through elements without needing to manage an index.

const array = [1, 2, 3, 4, 5];
for (const element of array) {
  console.log(element);
}

For…​in Loop

The for…​in loop is used to iterate over the properties of an object. It allows you to access each key in the object, making it useful for working with objects and their properties.

const obj = { a: 1, b: 2, c: 3 };
for (const key in obj) {
  console.log(`${key}: ${obj[key]}`); // Prints each key-value pair
}

Exiting Loops

You can exit a loop prematurely using the break statement. This is useful when you want to stop the loop based on a specific condition.

for (let i = 0; i < 10; i++) {
  if (i === 5) {
    break; // Exits the loop when i is 5
  }
  console.log(i); // Prints numbers from 0 to 4
}

You can skip the current iteration of a loop using the continue statement. This allows you to skip processing for certain conditions while continuing with the next iteration.

for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // Skips even numbers
  }
  console.log(i); // Prints odd numbers from 1 to 9
}

Functions

Functions are reusable blocks of code that perform a specific task. They allow you to encapsulate logic, making your code more organized and easier to maintain. Functions can take inputs (parameters) and return outputs (values).

function doubleIt(number) {
  return number * 2;
}
const result = doubleIt(5);

Default Parameters

Functions can have default parameters, which are used if no argument is provided for that parameter when the function is called. This allows for more flexible function definitions.

function greet(name = 'Guest') {
  return `Hello, ${name}!`;
}

Anonymous Functions

Anonymous functions are functions that do not have a name. They are often used as arguments to other functions or assigned to variables. They can be defined using the function keyword or as arrow functions.

const add = function(a, b) {
  return a + b;
};
const multiply = (a, b) => a * b;

Higher-Order Functions

Higher-order functions are functions that can take other functions as arguments or return functions as their result. They are commonly used in functional programming to create more abstract and reusable code.

function applyOperation(arr, operation) {
  return arr.map(operation);
}

DOM Scripting

DOM scripting refers to the process of manipulating the Document Object Model (DOM) using JavaScript. The DOM is a tree-like structure that represents the HTML or XML document, allowing you to access and modify its elements dynamically. This is essential for creating interactive web applications.

Web Browser Objects

  • Navigator: Provides information about the browser, such as its name, version, and platform.

  • Window: The browser window where the web page is displayed. It contains the viewport, which is the visible area of the web page.

  • Document: The DOM representation of the web page, which includes all the elements, attributes, and text content.

Selecting Elements

To manipulate elements in the DOM, you first need to select them. There are several methods available for selecting elements:

  • getElementById(id): Selects an element by its unique ID.

  • getElementsByClassName(className): Selects all elements with a specific class name.

  • getElementsByTagName(tagName): Selects all elements with a specific tag name.

  • querySelector(selector): Selects the first element that matches a CSS selector.

    const firstLink = document.querySelector("a");

  • querySelectorAll(selector): Selects all elements that match a CSS selector. Returns a NodeList, which is similar to an array but not exactly the same. You can iterate over it using a loop or convert it to an array if needed.

    const allLinks = document.querySelectorAll("a");
for (const link of allLinks) {
  console.log(link.href);
}

Creating and Modifying Elements

You can create new elements and modify existing ones in the DOM:

  • createElement(tagName): Creates a new element with the specified tag name.

  • appendChild(child): Adds a child element to a parent element.

  • removeChild(child): Removes a child element from a parent element.

  • setAttribute(name, value): Sets an attribute on an element.

  • getAttribute(name): Retrieves the value of an attribute from an element.

  • innerHTML: Gets or sets the HTML content of an element.

const newDiv = document.createElement("div");
newDiv.innerHTML = "<p>Hello, World!</p>";
document.body.appendChild(newDiv);

A common way to dynamically modify the style of an element is by using the setAttribute method to change the class of an element.

const element = document.getElementById("myElement");
element.setAttribute("class", "new-class");

Events

Events are actions or occurrences that happen in the system you are programming, which can be triggered by user interactions, system processes, or other sources. In web development, events are often associated with user actions like clicks, key presses, or mouse movements.

Event Listeners

Event listeners are functions that wait for specific events to occur and execute a block of code in response. They are essential for making web applications interactive. You can attach event listeners to HTML elements to respond to user actions.

document.getElementById('myButton').addEventListener('click', function() {
  alert('Button was clicked!');
});

Event Object

When an event occurs, an event object is created that contains information about the event, such as the type of event, the target element, and any additional data. You can access this object in your event handler to get more context about the event.

document.getElementById('myInput').addEventListener('input', function(event) {
  console.log('Input value:', event.target.value);
});

Network Requests

Network requests are essential for web applications to communicate with servers, fetch data, and send information. They allow your application to retrieve resources like HTML, CSS, JavaScript files, images, and data from APIs.

Fetch API

The Fetch API provides a modern way to make network requests in JavaScript. It is built on Promises, making it easier to handle asynchronous operations compared to the older XMLHttpRequest.

fetch("https://api.example.com/data")
  .then(response => {
    if (!response.ok) {
      throw new Error("Network response was not ok");
    }
    return response.json(); // Parse JSON data
  })
  .then(data => {
    console.log(data); // Handle the fetched data
  })
  .catch(error => {
    console.error("There was a problem with the fetch operation:", error);
  });
